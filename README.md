# EricDev — Modern Dark Neon Portfolio Website

A pixel-perfect, responsive portfolio website built with modern HTML5, CSS3, and JavaScript, faithfully reproducing the dark neon crimson aesthetic from the design reference.

## 🚀 Live Preview / How to Open

You can open the portfolio in two simple ways:

1. **Directly in your Browser**:
   - Double-click [`index.html`](index.html) in your file explorer, or right-click and choose **Open with > Chrome / Edge / Firefox**.
   - No build tools, servers, or dependencies required!

2. **Using VS Code / IDE Live Server**:
   - If using VS Code, right-click `index.html` and click **"Open with Live Server"**.

## 🎨 Design & Features Breakdown

- **Exact Visual Match**:
  - Deep carbon background (`#08080a`) with glowing crimson red neon light curves, radial atmospheric blurs, and glassmorphic cards.
  - Plus Jakarta Sans & Outfit typography with precision red highlighted keywords (`Impact.`, `Best`, `My Work`, `Reality`, `Say`).
  - Hero Section with slanted 3D-perspective laptop mockup running glowing `</>` code interface, floating skill badges (`Web Development`, `App Development`, `UI/UX Design`), and 4-client avatar trust stack.

- **Interactive Components (Everything Works)**:
  - **Sticky Header & ScrollSpy**: Navigation links automatically highlight the active section on scroll; smooth scrolling with offset compensation.
  - **Mobile Drawer Menu**: Smooth sliding drawer navigation with hamburger icon toggle for mobile screens.
  - **Animated Stat Counters**: Numbers count up smoothly (`0` → `50+`, `100%`, `2+`) when scrolled into view.
  - **Portfolio Carousel & Project Inspector**: Interactive slider with next/prev buttons and swipe support. Clicking any project card opens a comprehensive Case Study Modal with client info, key deliverables, tech stack, and live demo/repo links.
  - **Services Explorer**: "Learn More" and "Explore All Services" open an in-depth service breakdown modal with deliverables and direct inquiry integration.
  - **Testimonial Slider**: Cycles through multiple client testimonials with glowing star ratings, pagination dots, and arrow controls.
  - **Interactive Contact / Hire Me Modal**: Complete inquiry form with validation, submit spinner, toast notification confirmation, and localStorage persistence.
  - **Ambient Particle Canvas**: Subtle particle animation that smoothly drifts and interacts with mouse cursor motion.
  - **Back to Top**: Smooth scroll-to-top button with hover glow effects.
